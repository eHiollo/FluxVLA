# 双 A10 毛巾／纸盒任务：资源与配置盘点

核对日期：2026-10-19。代码基线：`kaanh_follower_vr` 分支。

目标是整理：**我们已经有什么、哪些可以沿用、还需要补齐什么信息。**
本次只盘点资源、配置和接口缺口，不选择算法，不制定训练或控制技术路线，也不修改运行配置。
“代码已具备”“配置中写了”“设备实际可用”是不同状态，下面分别说明。

## 1. 先看结论

- 目前有单台 A10 的 VR 输入、机器人通信、相机接口、旧夹爪接口和模型推理适配，可作为双臂工程的基础。
- 当前 A10 原生配置和运行流程仍是**单臂**；不是再填一个 IP 就已经支持双臂。
- 已收到知行执行器资料，但**具体夹爪型号尚未确认**；现有夹爪驱动不能直接当作知行驱动使用。
- 已有单臂数据和权重，不代表已经有双臂叠毛巾／纸盒的数据、模型或任务验证结果。
- 新 VR 流程能保存诊断日志，完整训练数据录制尚未接通。日志不能直接当作演示数据集。

### 3.1 从手册可以确认的配置资料

下表的页码均为 **PDF 阅读器显示的页面序号**，不是页面下方的印刷页码。
这些是所附手册的约定，实际设备仍需按具体型号和已保存参数核对。

| 项目 | 手册中的信息 | 来源 |
| --- | --- | --- |
| 适用产品 | 多款平动两指手、协作两指手；并非只对应某一款夹爪 | 执行器手册第 3 页 |
| 供电／接线 | 标准线缆表标示 24V 供电、接地及信号线；所需电流和电源容量仍需产品规格 | 执行器手册第 7～8 页 |
| 通信方式 | IO 或 RS485；手册明确两者不同时使用 | 执行器手册第 7 页 |
| 数据协议 | RS485 上使用 Modbus RTU，支持 `0x03`、`0x06`、`0x10` 功能码 | 执行器手册第 14 页 |
| 串口参数 | 软件手册给出的默认参数为 115200、8 数据位、无校验、1 停止位，即 8N1 | 软件手册第 27、36 页 |
| 设备地址 | 手册默认从站 ID 为 1，可修改；实际值需读取或向供应商确认 | 执行器手册第 15 页、软件手册第 36 页 |
| 位置表示 | 手册使用千分比映射；临时目标位置占两个寄存器 | 执行器手册第 13、18 页 |
| 速度／力矩表示 | 相对于设备相应最大参数的百分比，不能直接当作 mm/s 或牛顿 | 执行器手册第 18～19 页 |
| 可用反馈 | 有运动状态、报警、用户位置、用户转速和电流等字段 | 执行器手册目录第 5 页及附录 |

手册第 3 页列出的型号为：`CTPM2F40S-D`、`CTPM2F60S-D`、`CTPM2F60L-D`、
`CTPM2F50F-D`、`CTAG2F90-D`、`CTAG2F120-D`、`CTAG2F120S-D`、`CTAG2F85`。
**这只是手册适用范围，不是你们已选定的型号清单。**

### 3.2 和现有夹爪配置的区别

| 项目 | 现有 FluxVLA 原夹爪 | 本次知行资料 |
| --- | --- | --- |
| 协议 | 原夹爪总线舵机报文 | Modbus RTU，不能只改波特率就复用 |
| 波特率／ID | 驱动默认 1000000、舵机 ID 10 | 手册默认 115200、从站 ID 1；实物待核对 |
| 开度 | 现有 100mm 型夹爪配置工作范围为 0～85mm | 实际开口、零点、方向及千分比到 mm 的对应关系待确认 |
| 力相关信息 | 原驱动按原硬件字段解释 | 力矩百分比／电流不自动等于真实夹持力，是否有力传感器待确认 |
| 配套设备 | 当前已有原夹爪串口路径示例 | 主机或控制器的 RS485 接口、转换器、线缆和供电需另行登记 |
| 接口适配 | 已有读状态和设定开度等接口 | 尚缺对应型号的协议驱动与配置，不能宣称已接通 |

如果两个知行夹爪接在**同一条 RS485 总线**上，需要分别确认不冲突的从站地址；如果分别接在不同串口，总线地址可分别管理。
还需明确由哪台主机负责通信，避免两个程序同时占用同一设备。这里只登记配置需求，不选择接线方案。
