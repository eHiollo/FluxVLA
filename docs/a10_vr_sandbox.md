# VR 映射测试台（不连接实机）

在 FluxVLA_90hz 仓库、fluxvla Python 环境中启动：

```bash
python scripts/preview_vr_mapping.py
```

默认读取 `configs/a10/a10_dual_vr.py` 的 VR 输入、
左右绑定和参考控制参数，固定以 90 Hz 计算。即使配置包含实机与夹爪设置，
测试台也不会构造机器人 runtime、机器人 operator、夹爪或相机，不读姿态标定文件。
只启动 VR HTTPS/WebSocket 服务，虚拟反馈为上一周期虚拟指令，不是实机或动力学仿真。

启动后终端会打印本机测试地址及可用局域网地址（忽略代理虚拟网卡）：

- 头显打开服务首页（默认 `https://本机局域网IP:8443/`），接受本地证书并进入 VR。
- 运行服务的电脑优先打开 `https://127.0.0.1:8443/vr-sandbox.html`，避免代理虚拟网卡干扰。
- 其他电脑使用与其同网段的本机局域网 IP 加 `/vr-sandbox.html`；电脑页只是观察者，不占用手柄输入连接。

如旧遥操作进程占用了端口，先在其终端 Ctrl+C 退出；测试台不会自动结束其他进程。
需要修改网络地址或端口时，沿用配置覆盖方式：

```bash
python scripts/preview_vr_mapping.py --cfg-options \
  teleop.input.network.host_ip=0.0.0.0 \
  teleop.input.network.https_port=8443 \
  teleop.input.network.websocket_port=8442
```

检查配置而不启动服务：

```bash
python scripts/preview_vr_mapping.py --preview
```

## 如何对照

页面左侧为原始 VR 追踪空间（+Y 向上），中间是旧工具锚点映射，右侧是世界平移映射。
后两者共用一份输入、相同参数、相同初始位姿及相同局部旋转算法。
统一工作台视角：世界 +X 向前、+Y 向左、+Z 向上。
左臂基座 +X 前、+Y 左、+Z 上；右臂基座 +X 后、+Y 右、+Z 上，
相对左基座绕 Z 转 180°，两者均为右手系。工具轴均为 +X 上、+Y 右、+Z 前，
默认两臂夹爪都朝工作台前方，即工具 +Z 分别指向左基座 +X、右基座 −X；左右颜色指物理手柄，状态表同时显示配置中的逻辑臂绑定。

1. 先松开两侧侧键和前扳机，自然握持手柄。
2. 按住某一侧侧键，沿固定方向移动，观察两种平移轨迹；当前新配置仅平移、锁定姿态。
   只按前扳机也能接管，可平移和旋转；两键同时按以前扳机为准。
3. 松开、换握姿、重新接管，再沿同一方向移动。
4. 新模式的基座平移方向不随接管姿态改变；旋转仍沿用局部增量。

显示时将各臂基座位置、姿态、工具轴和轨迹统一转换到工作台世界，不做左手系镜像。
左右虚拟基座在工作台 Y=+0.25/-0.25 m，仅用于画面区分，不代表实际安装间距。
手柄物理左右侧与配置中的逻辑臂名称分开：即使 hand_to_arm 交换，物理左侧仍使用左臂基座。

新模式先把 WebXR 世界位移转换为工作台位移，再用各基座旋转的逆变换转成本臂基座位移，
因此相同 VR 世界位移可让两臂沿相同工作台方向移动，而右臂本地 X/Y 分量符号相反。
旋转仍用原工具局部增量算法。测试台不连接机器人；实机新配置另行通过
world_position_axis_remap 配置相同的每手方向，原实机入口和协议保持原样。

旧模式继续使用工具局部轴映射 `(dx,dy,dz) → (dy,dx,-dz)`。
新模式使用独立的世界轴映射 `(dx,dy,dz) → (-dz,-dx,dy)`：
VR 前推（−Z）→ 工作台前方（+X），左移（−X）→ 左方（+Y），上移（+Y）→ 上方（+Z）。
这采用固定方向约定，不自动估计操作者转身或头显重新居中后的水平朝向。

## 界面操作

- 拖动视图改变观察角度，滚轮缩放；三视图共用视角操作。
- 冻结只暂停画面；后台继续接收与计算，冻结时禁止重置。
- 清空轨迹只清画面，保留虚拟目标；轨迹最多保留最近 10 秒、每手每视图 300 点。
- 双手侧键和前扳机均松开后可切换“工具 +Z 朝工作台前方 / 朝下”并重置；重置同时清除两种模式的虚拟锚点。
- 输入过期、丢失追踪或异常时，停止更新对应侧目标并置灰；松开侧键和前扳机、恢复有效追踪后重新接管。
- 更新频率按新的输入样本计算；输入年龄保留原接收时间，不因重复读取变新。

测试台只用于检查输入、坐标映射和前端目标连续性，不模拟整臂 IK、碰撞、负载、
真实夹爪开合或控制器跟随，不能据此判断实机抖动与安全工作空间。
Ctrl+C 关闭测试服务。

## 开发验证

```bash
python -m unittest discover -s test -p 'test_vr_sandbox.py' -v
python -m unittest discover -s test -p 'test_vr*.py' -q
```

新增观察接口 `/api/vr-sandbox` 不消费输入。
`POST /api/vr-sandbox/reset` 只接收 `{"preset":"down"}` 或 `{"preset":"horizontal"}`，
通过队列交给计算循环；侧键或前扳机按住时拒绝，执行前再次检查，绝不转发到机器人协议。
