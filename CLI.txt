 终端二：启动机器人控制台
    启动kaanhbin程序
    conda activate fluxvla

    单臂（192.168.0.125；与推理共享连接）：
    python scripts/a10_control.py --config configs/a10/a10_operator.py --shared

    双臂（192.168.0.150）：
    python scripts/a10_control.py --config configs/a10/a10_dual_arm_operator.py

    修改机器人 IP：在 shell 前加 --host 新IP，覆盖配置中的 operator.host。
    不带 --config 时默认单臂配置 configs/a10/a10_operator.py。
    切换单臂/双臂使用 --config；每个配置的 init_position 对应这台机器人。

    控制台执行动作时，可直接输入：
    stop
    取消当前和停止前排队的命令，停止本地下发并请求退出 follower；控制台保留。
    stop 只有收到 inactive + Stopped 反馈才报告机器人停止成功；它不是硬件急停。

python - <<'PY'
import socket
import struct
import time

target = [21, 38, -131, 28, 100, 10,
          -18, -36, 128, -20, -100, 5]

payload = ('jp --motor_pos=[' +
           ','.join(map(str, target)) + ']').encode('utf-8')

packet = struct.pack('<IIQqqq', len(payload), 0, 0, 0, 0, 0) + payload

with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as sock:
    print('向 192.168.0.150:9999 持续发送目标，Ctrl+C 停止发送')
    try:
        while True:
            sock.sendto(packet, ('192.168.0.150', 9999))
            time.sleep(1 / 30)
    except KeyboardInterrupt:
        print('\nUDP 发送已结束')
