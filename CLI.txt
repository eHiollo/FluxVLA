一、双臂 VR：世界坐标平移 + 局部旋转

只检查配置，不启动服务或连接设备：
python scripts/teleoperate.py --config configs/a10/a10_dual_vr.py --preview

只看手柄输入，不连接机械臂或夹爪（会启动 VR 服务）：
python scripts/teleoperate.py --config configs/a10/a10_dual_vr.py \
  --cfg-options teleop.vr_only=True

只读机器人反馈，不启动跟随、不发送运动：
python scripts/teleoperate.py --config configs/a10/a10_dual_vr.py --observe

实机遥操作（默认实机 + 两只知行夹爪，不自动使能或归位）：
python scripts/teleoperate.py --config configs/a10/a10_dual_vr.py

临时调整手感（不改配置默认值）：
python scripts/teleoperate.py --config configs/a10/a10_dual_vr.py \
  --cfg-options teleop.input.mapping.pos_scale=1.2 \
    teleop.input.mapping.angle_scale=0.8 teleop.input.mapping.fine_scale_factor=0.6

夹爪默认电机速度50%、目标变化速率4500 raw/s、最大领先900 raw。
临时降低夹爪参数示例：
python scripts/teleoperate.py --config configs/a10/a10_dual_vr.py \
  --cfg-options teleop.zx_grippers.devices.left.speed=15 \
    teleop.zx_grippers.devices.right.speed=15 \
    teleop.zx_grippers.target_rate_raw_s=3000 teleop.zx_grippers.max_lead_raw=600

图形化映射测试台：
python scripts/preview_vr_mapping.py

二、双臂数据录制：独立30Hz真实反馈和三相机采样

续录现有数据集（新建时改用新目录并去掉 record.resume=True）：
python scripts/teleoperate.py \
  --config configs/a10/a10_dual_vr.py \
  --record-config configs/a10/a10_dual_arm_record.py \
  --record-options \
    record.root=datasets/cloth_folding_04 \
    'capture.task=Fold the clothes' \
    record.resume=True


已有数据可继续使用原绝对路径，例如：
  record.root=/home/robot/VLA/FluxVLA_90hz/datasets/dual_90hz_test record.resume=True
更换配置入口不会移动原数据。检查控制延迟可另加 --measure-vr-latency。

只检查录制按键和VR延迟，不连接机器人、相机或夹爪：
python scripts/teleoperate.py --config configs/a10/a10_dual_vr.py \
  --record-config configs/a10/a10_dual_arm_record.py \
  --check-record-buttons --measure-vr-latency

三、双臂控制台与设备检查

控制台与VR默认复用本地共享连接，先开哪个都可以：
python scripts/a10_control.py --config configs/a10/a10_dual_arm_operator.py

控制台接管/回位后恢复VR：控制台输入 stop_follower，双手松键、摇杆回中，再按侧键接管。
共享服务日志：work_dirs/a10/shared_control/service.log

查看设备身份与接口匹配：
python scripts/a10_devices.py

python scripts/a10_devices.py --snapshot

python scripts/a10_devices.py --update

python scripts/a10_devices.py --check-grippers

四、双臂训练与推理

训练适配示例：configs/pi05/pi05_paligemma_a10_dual_fold_10steps.py。
当前部署默认使用50k模型，不使用10步接口测试权重。
模型准备、训练数据约定和推理说明见 docs/a10_dual_fold.md。

FluxVLA模型服务（独立终端）：
python -m fluxvla.engines.runners.serving.serve \
  --config configs/a10/a10_dual_inference.py \
  --model fluxvla --from-config --dtype fp32 --host 127.0.0.1 --port 5556

统一双臂客户端（默认motion，操作前确认现场状态并手动使能）：
python scripts/inference.py --config configs/a10/a10_dual_inference.py

选择OpenPI模型（服务在OpenPI侧启动）：
python scripts/inference.py --config configs/a10/a10_dual_inference.py --model openpi

仅预览、不连接模型或设备：
python scripts/inference.py --config configs/a10/a10_dual_inference.py \
  --cfg-options inference.mode=preview

默认follower倍率12%、手动倍率100%，电机加速度目标±375°/s²。
运动前回读加速度，匹配则跳过写入，不匹配由公共预检按控制器权限和状态处理。
不自动使能或为自动预检停止/卸载其他运动；不满足写入条件时清晰报错。
遥操作和m_init使用双臂基础配置的加速度目标±1000°/s²。
每块保留20个30Hz策略点，每点重复两遍，以60Hz发送40包；不做客户端规划或均值补偿。
发完后保持follower运行，实际12轴误差≤0.5°即停止，无固定稳定等待；
停止及停止后新反馈核验通过后，才取得新观测。到位超时默认30秒。
默认100万轮、单次模型超时3600秒、双夹爪报警warn；故障和过期反馈保护保留。
可选推理等待期只读反馈诊断：--cfg-options inference.trace_inference_feedback=True。

kaanhbin调整加速度
。项目规定 write_motor 必须在程序**未加载（Unloaded）**时执行，仅停止程序还不够。

在控制器命令终端依次操作：

1. 如果程序正在运行，先停止：

   pgmctrl --stop
2. 卸载当前程序：

   pgmctrl --unload

   卸载是解除当前加载，不是删除程序文件。
3. 卸载成功后，保持厂家权限、手动模式、未使能，重新发送你那条完整的 write_motor 指令。
4. 写入成功后读取确认：

   read_motor --id=0


项目控制台加速度快捷命令（需退出并重新启动控制台加载）：
set_acc 400                 全部12轴设为 max_acc=400、min_acc=-400，单位 °/s²
set_acc 400 --all           同上
set_acc 400 --id=0          只修改控制器电机索引0（不是slave_id）

也可单次运行：
python scripts/a10_control.py --config configs/a10/a10_dual_arm_operator.py set_acc 400

要求厂家权限、手动模式、无故障。指令自动停止follower/程序、卸载至Unloaded，
然后掉使能并确认Disabled/Stopped后逐轴写入完整配置，仅更改max_acc/min_acc。
无需手工拼JSON；每轴写后回读全部12轴，其他字段或未选择电机有变化就中止。
原配置、期望配置、逐条控制器回复、部分完成列表和验证结果保存在
work_dirs/a10/motor_acc_commands/<时间戳>/。
超时结果可能未知，不自动重试或回滚；失败时检查error.json和commands.json。
结束保持未使能、Unloaded，不自动加载程序或使能；此电机限制也影响其他运动方式。
Python调用：from fluxvla.engines.operators.kaanh_commands.set_acc import set_acceleration
控制台角色operator在新命令上下文调用 set_acceleration(robot, 400, motor_id=None)。
